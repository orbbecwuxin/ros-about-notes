System setupï

Set localeï

Make sure you have a locale which supports UTF-8. If you are in a minimal environment (such as a docker container), the locale may be something minimal like POSIX. We test with the following settings. However, it should be fine if youâre using a different UTF-8 supported locale.

📝 译文： 请确保你使用的语言环境支持 UTF-8。如果你使用的是最小化环境（例如 Docker 容器），语言环境可能非常有限，比如 POSIX。我们使用以下设置进行测试。不过，如果你使用其他支持 UTF-8 的语言环境，应该也不会有问题。 
$ locale  # check for UTF-8

$ sudo apt update && sudo apt install locales
$ sudo locale-gen en_US en_US.UTF-8
$ sudo update-locale LC_ALL=en_US.UTF-8 LANG=en_US.UTF-8
$ export LANG=en_US.UTF-8

$ locale  # verify settings

Enable required repositoriesï

You will need to add the ROS 2 apt repository to your system.

📝 译文： 你需要将 ROS 2 apt 软件仓库添加到你的系统中。

First ensure that the Ubuntu Universe repository is enabled.

📝 译文： 首先确保已启用 Ubuntu Universe 软件仓库。 
$ sudo apt install software-properties-common
$ sudo add-apt-repository universe

The ros-apt-source packages provide keys and apt source configuration for the various ROS repositories.

📝 译文： ros-apt-source 软件包为各个 ROS 仓库提供密钥（keys）和 apt 源配置。

Installing the ros2-apt-source package will configure ROS 2 repositories for your system. Updates to repository configuration will occur automatically when new versions of this package are released to the ROS repositories.

📝 译文： 安装 ros2-apt-source 软件包将为你的系统配置 ROS 2 仓库。当这个软件包的新版本发布到 ROS 仓库时，仓库配置的更新会自动发生。
💡 理解： ros2-apt-source 的作用就是把 ROS 2 软件源配置 + 签名密钥打包成一个 Debian 软件包。 
$ sudo apt update && sudo apt install curl -y
$ export ROS_APT_SOURCE_VERSION=$(curl -s https://api.github.com/repos/ros-infrastructure/ros-apt-source/releases/latest | grep -F "tag_name" | awk -F'"' '{print $4}')
$ curl -L -o /tmp/ros2-apt-source.deb "https://github.com/ros-infrastructure/ros-apt-source/releases/download/${ROS_APT_SOURCE_VERSION}/ros2-apt-source_${ROS_APT_SOURCE_VERSION}.$(. /etc/os-release && echo ${UBUNTU_CODENAME:-${VERSION_CODENAME}})_all.deb"
$ sudo dpkg -i /tmp/ros2-apt-source.deb

Install development tools (optional)ï

If you are going to build ROS packages or otherwise do development, you can also install the development tools:

📝 译文： 如果你打算构建 ROS 软件包或进行其他开发工作，你还可以安装开发工具：

Warning

On Ubuntu 24.04 installs your apt sources may only include the base noble suite. This can cause dependency conflicts when installing ros-dev-tools.

Check /etc/apt/sources.list.d/ubuntu.sources and ensure the Suites: line includes noble-updates and noble-backports:

$ grep Suites /etc/apt/sources.list.d/ubuntu.sources

If noble-updates or noble-backports are missing then edit the file and update the line to:

Suites: noble noble-updates noble-backports

Then run:

$ sudo apt clean && sudo apt update && sudo apt full-upgrade -y

$ sudo apt update && sudo apt install ros-dev-tools

Install ROS 2ï

Update your apt repository caches after setting up the repositories.

📝 译文： 在设置好仓库之后，更新你的 apt 仓库缓存。 
$ sudo apt update

ROS 2 packages are built on frequently updated Ubuntu systems. It is always recommended that you ensure your system is up to date before installing new packages.

📝 译文： ROS 2 软件包是在频繁更新的 Ubuntu 系统上构建的。始终建议你在安装新软件包之前，确保系统已经更新到最新。 
$ sudo apt upgrade

Desktop Install (Recommended): ROS, RViz, demos, tutorials.

📝 译文： 桌面安装（推荐）：ROS、RViz、示例（demos）、教程（tutorials）。 
$ sudo apt install ros-jazzy-desktop

ROS-Base Install (Bare Bones): Communication libraries, message packages, command line tools. No GUI tools.

📝 译文： ROS 基础安装（精简版）：通信库、消息软件包、命令行工具。不包含图形化工具。 
$ sudo apt install ros-jazzy-ros-base

Install additional RMW implementations (optional)ï

The default middleware that ROS 2 uses is Fast DDS, but the middleware (RMW) can be replaced at runtime. See the guide on how to work with multiple RMWs.

📝 译文： ROS 2 使用的默认中间件是 Fast DDS，但中间件（RMW）可以在运行时替换。可以参考指南了解如何与多个 RMW 协同工作。

Setup environmentï

Set up your environment by sourcing the following file.

📝 译文： 通过 source 以下文件来设置你的环境。 
$ source /opt/ros/jazzy/setup.bash

Note

Replace .bash with your shell if youâre not using bash. Possible values are: setup.bash, setup.sh, setup.zsh.

Try some examplesï

If you installed ros-jazzy-desktop above you can try some examples.

📝 译文： 如果你在上面安装了 ros-jazzy-desktop，你可以尝试一些示例。

In one terminal, source the setup file and then run a C++ talker:

📝 译文： 在一个终端中，source setup 文件，然后运行一个 C++ 的 talker 程序： 
$ source /opt/ros/jazzy/setup.bash
$ ros2 run demo_nodes_cpp talker

In another terminal source the setup file and then run a Python listener:

📝 译文： 在另一个终端中，source setup 文件，然后运行一个 Python 的 listener 程序： 
$ source /opt/ros/jazzy/setup.bash
$ ros2 run demo_nodes_py listener

You should see the talker saying that itâs Publishing messages and the listener saying I heard those messages. This verifies both the C++ and Python APIs are working properly. Hooray!

📝 译文： 你应该能看到 talker 显示它正在发布消息，listener 显示它收到了那些消息。这验证了 C++ 和 Python 两套 API 都能正常工作。太棒了！

If you want to use other RMW implementations, you can check the guide.

📝 译文： 如果你想使用其他 RMW 实现，可以查看这份指南。

📝 译文： 继续通过教程和示例（demos）来配置你的环境、创建你自己的工作空间和软件包，并学习 ROS 2 的核心概念。

Uninstallï

If you need to uninstall ROS 2 or switch to a source-based install once you have already installed from binaries, run the following command:

📝 译文： 如果你已经从二进制包完成安装，之后需要卸载 ROS 2 或切换到基于源码的安装，请运行以下命令： 
$ sudo apt remove '~nros-jazzy-*' && sudo apt autoremove

You may also want to remove the repository:

📝 译文： 你可能还想删除该软件仓库： 
$ sudo apt remove ros2-apt-source
$ sudo apt update
$ sudo apt autoremove
$ sudo apt upgrade # Consider upgrading for packages previously shadowed.
