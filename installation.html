Installationï

Options for installing ROS 2 Jazzy Jalisco:

📝 译文： 安装 ROS 2 Jazzy Jalisco 的选择：

Binary packagesï

Binaries are only created for the Tier 1 operating systems listed in REP-2000. If you are not running any of the following operating systems you may need to build from source or use a container solution to run ROS 2 on your platform.

📝 译文： 二进制包仅为 REP-2000 中列出的 Tier 1 操作系统构建。如果你当前运行的操作系统不在其中，你可能需要从源码构建，或使用容器方案在你的平台上运行 ROS 2。

We provide ROS 2 binary packages for the following platforms:

📝 译文： 我们提供以下平台的 ROS 2 二进制包：

  • Ubuntu Linux (amd64 / aarch64) - Noble Numbat (24.04)

    • deb packages (recommended)

    • binary archive

  • Red Hat Enterprise Linux 9 (amd64)

    • RPM packages (recommended)

    • binary archive

  • Windows 10 (amd64)

    • Windows Binary (VS 2019)

Building from sourceï

We support building ROS 2 from source on the following platforms:

📝 译文： 我们支持在以下平台上从源码构建 ROS 2：

  • Ubuntu Linux 24.04

  • Windows 10

  • RHEL-9/Fedora

  • macOS

Which install should you choose?ï

Installing from binary packages or from source will both result in a fully-functional and usable ROS 2 install. Differences between the options depend on what you plan to do with ROS 2.

📝 译文： 无论是从二进制包安装，还是从源码构建，都会得到一个功能完整、可用的 ROS 2 安装。两种方式之间的差异取决于你计划用 ROS 2 做什么。

Binary packages are for general use and provide an already-built install of ROS 2. This is great for people who want to dive in and start using ROS 2 as-is, right away.

📝 译文： 二进制包用于常规使用，并提供已经构建好的 ROS 2 安装。这对那些想要立即上手、直接开始使用 ROS 2 的人来说非常合适。
💡 理解： 短语笔记：are for general use and provide…（用于常规使用并提供…）；dive in and start using（立即上手使用）；is great for…（非常适合…）。

Linux users have two options for installing binary packages:

📝 译文： Linux 用户有两种安装二进制包的选项：

  • Packages (debs or RPMS, depending on the platform)

  • binary archive

Installing from packages is the recommended method, as it installs necessary dependencies automatically and also updates alongside regular system updates. However, you need root access in order to install deb packages. If you donât have root access, the binary archive is the next best choice.

📝 译文： 推荐使用软件包安装，因为它会自动安装必要的依赖项，并随系统更新一同更新。但是，安装 deb 软件包需要 root 权限。如果您没有 root 权限，二进制归档文件就是最佳备选方案。

Windows users who choose to install from binary packages only have the binary archive option (deb packages are exclusive to Ubuntu/Debian).

📝 译文： Windows 用户如果选择从二进制软件包安装，则只有二进制归档选项（deb 软件包是 Ubuntu/Debian 独有的）。

Building from source is meant for developers looking to alter or explicitly omit parts of ROS 2âs base. It is also recommended for platforms that donât support binaries. Building from source also gives you the option to install the absolute latest version of ROS 2.

📝 译文： 从源代码构建适用于希望修改或明确省略 ROS 2 基础代码部分内容的开发者。对于不支持二进制文件的平台，也推荐使用这种方法。此外，从源代码构建还可以让你选择安装 ROS 2 的最新版本。

Contributing to ROS 2 core?ï

If you plan to contribute directly to ROS 2 core packages, you can install the latest development from source which shares installation instructions with the Rolling distribution.

📝 译文： 如果你计划直接为 ROS 2 核心软件包做出贡献，你可以从源代码安装最新的开发版本，该版本与 Rolling 发行版共享安装说明。
